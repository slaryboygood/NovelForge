## 开始一个故事

1. 启动 NovelForge，打开 <http://127.0.0.1:8000/>。
2. 选择“新故事起点”，再点“开始构筑”或“新建故事”。可以从世界观、人物灵感或开场事件开始。
3. 在当前步骤选择一个或多个方向，也可以填写自己的设定。
4. 点击“确认并继续”，系统会根据已确认内容给出下一步可选方向。

先写人物或事件时，可以使用自定义方向；依赖世界观的模板仍需满足条件。保存灵感后会回到尚未完成的前置设定，不自动填默认值。已保存的灵感不会丢失。

“已保存故事”用于切换，新建不会删除旧故事。刷新恢复当前查看的故事。

## 可选设计树

基础十步之外，可分区补充定位与主题、生活背景、主角、同伴与对手、开篇/结局与长期规划、叙事方式。只有相关前置确认后，节点才解锁；所有深度节点都可不填。

目录有 32 个节点，包含 12 类开篇、24 个原创短例。示例不是已经发生的剧情。自己的设定可以保存，但有限规则不能解释全部自由文本，未自动适配的内容会提示。

世界和人物选择进入蓝图快照；视角进入章纲，主题、错误信念、结局、阶段目标、支线职责和伏笔回收等保留为作者设计要求，不改写实际路线事实。阶段目标与结局衔接在整合大纲时列为“未来阶段建议（未发生，待安排）”，不把当前路线当成已经写好的完整长篇。

## 返回与改选

点击左侧已完成步骤可以返回。改动上游选择后，系统保留下游内容并显示“待复核”，不会直接删除作者已经写下的设定。

按顺序重新确认待复核步骤后，再生成新蓝图。旧蓝图和旧大纲版本仍保留，但不能继续作为当前写作输入。

## 生成故事蓝图

十步全部完成后：

1. 查看自动整合的蓝图；需要时点击“整合并查看故事蓝图”。
2. 阅读故事前提和十个分节。
3. 有冲突时先返回修改选择。
4. 无阻断冲突时点击“确认故事蓝图”。

蓝图确认不等于正文提交，它只是把分散选择整合成一份可追溯的故事设计。

## 推演后生成四级大纲

确认蓝图后点击“开始 / 继续旅程”。前三次选择完成后可收束或继续，后续最多到第八次选择。每步根据已发生结果开放行动，不能提前使用尚未核实的秘密。

历史记录中的“另开路线”保留原路线，分支选择互不覆盖；可通过路线列表切换。阶段结束后点“用当前路线整合大纲”，将当前分支事实写入大纲候选。

依次生成并确认：

1. 全书主线
2. 卷纲
3. 篇章纲
4. 详细章纲

每层条目都可以展开查看开始状态、结束状态和结尾推力。只有上一层确认后，下一层按钮才会解锁。

“编辑此条”修改后另存版本，再确认。导出按钮下载中文 Markdown，含设计要求与路线来源。“重新生成新版本”不会覆盖旧稿；路线推进或上层变化会让下层待复核。

当前路线只是全书的一段。故事规模、后续阶段、结局衔接仍可能列为待决定项，不等于已经自动写好完整长篇。


## 完成

详细章纲确认后即完成构筑。当前版本不提供章节正文生成、编辑或正式提交。刷新页面会恢复当前构筑会话。
