# 写作风格指南（Novel Reboot v2）——小白爽文语言

## 语言目标

简单、顺畅、直接、有画面、有动作、有情绪、容易追读。不要晦涩，不要追求所谓高级感。

## 表达原则

1. **动作与对话自己表达信息**：禁止"先描述一个现象，然后由旁白完整解释这个现象意味着什么"。
2. **短句优先**：战斗与紧张场景用短句；段落不要太长；一段一个信息单位。
3. **有画面**：写"剑光劈开静电史莱姆，黏液溅了零一脸"，不写"灵能输出效率显著提升"。
4. **有情绪**：主角被打脸会脸红，捡到蓝装会狂笑，同伴受伤会急得跳脚。

## 禁止清单（大量出现即视为 AI 感）

- 序意识到…… / 序分析…… / 序判断…… / 数据显示…… / 这意味着…… / 换句话说…… / 从逻辑上…… / 拓扑显示…… / 电势证明……
- 先现象后解释的旁白结构
- 连续参数解释（面板刷屏、几百字说明）
- 所有角色说同一种理性、完整、正确的语言
- 角色坐下来讨论哲学/文明/自由意志
- 技术术语替代动作（"他注入一段脉冲"→"他挥剑劈下"）

## 系统提示使用限制

- 只在以下情况使用【】提示：升级、获得技能、获得装备、任务变化、重大世界事件、首次发现特殊机制。
- 提示必须短，例如：
  - 【击杀：噬流虫王】
  - 【等级提升：Lv.7 → Lv.8】
  - 【获得：蓝色装备·雷纹护臂】
- 禁止几百字说明面板。

## 人物语言

- 人物说话必须像不同的人：主角（嘴硬吐槽）、队友（各有口头习惯）、奸商（贪财油滑）、女巫（神秘断续）、老兵（简短沧桑）、贵族（傲慢拿腔）、村民（朴实直接）、Boss（压迫感台词）。
- 允许：吐槽、误会、嘴硬、打脸、装逼、害怕、兴奋、贪财、嫉妒、冲动、友情、暧昧、玩笑。

## 节奏

- 一章内至少有一个动作场面或冲突升级；每 3-5 章一个小爽点，每卷有中爽点、大爽点与爆点。
- 禁止连续多章只有调查、谈话或解释。
- 升级与获得装备的段落要短促有力，立刻用下一场战斗证明新力量。

# 该多写 / 该少写（Outline Refinement 追加）

## 应该多写
- 人物动作：奔跑、挥剑、闪避、翻墙、摔倒、爬起（战斗与日常都写动作）
- 对白：人物语言差异化，一场戏至少两段有信息/有情绪的对白
- 表情：脸红、咬牙、瞪眼、发抖、狂笑、挑眉（拟人化身体反应）
- 视觉变化：怪物外形、装备发光、技能特效、地图切换的第一眼
- 战斗动作：短句连击、招式拆解、伤害反馈（"一剑劈开，黏液溅了满脸"）
- 装备变化：穿新装备的仪式感（"他掂了掂雷纹护臂，沉得刚好"）
- 怪物外形：每只重要怪物出场先给外形再给战斗
- 城市生活：酒馆、市场、讨价还价、节庆（服务人物与节奏）
- 队友互动：斗嘴、默契、互坑、护短

## 应该少写
- 技术说明：任何"原理/机制/参数"解释（底层原理属于作者后台）
- 长段世界观解释：设定靠事件和对话带出，不靠旁白
- 抽象独白：角色不进行哲学/人生/文明反思
- 复杂电子参数：灵能数字只出现在【】提示，且短
- 系统说明：面板只出现在升级/获得装备/任务变化等关键节点
- AI式总结句："这意味着/换句话说/从逻辑上"
- 先现象后解释结构：描写现象后立刻让动作/对话/结果接续，不由旁白解释

## 章节字数原则
一章一个主要事件 + 必要的副变化 + 明确章尾钩子。不为一章塞三个无关事件凑字数。
