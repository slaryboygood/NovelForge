# 禁止复制清单

> 本文件是参照隔离边界。研究结果只能转化为抽象叙事方法，不能转化为参考书的具体表达或设定。

## 一、严禁复制的内容

- 参考书的角色姓名、生命名称、地点、文明、组织和专有术语。
- 具体起源、成长路线、身体结构、生态关系和能力获得机制。
- 独特世界层级、空间结构、历史真相和终局答案。
- 特定篇章的事件顺序、敌我关系、谜底与反转组合。
- 原文句式、比喻、对白、章节标题和标志性表达。
- 将参考书中的某个生命或文明仅改名后放入《硅基升维》。
- 按参考书的篇章顺序逐段对应《硅基升维》的卷与篇章。

## 二、不能伪装成抽象方法的复制

以下做法即使改了名词，也仍然不允许：

- 复刻同一种主角起源与第一轮成长事件，只替换材料名称。
- 复刻某一独特生态谜题的证据顺序与答案。
- 复刻具体文明冲突，再把角色改成硅基生命或 AI。
- 使用相同的世界扩展阶梯和终局宇宙解释。
- 要求模型“像参考书作者那样写”或模仿其语气。

## 三、允许迁移的抽象能力

- 问题解决后自然产生更深问题。
- 非人载体决定感知、行动与认知。
- 成长由现实失败触发，并带来成本。
- 新环境改变规则，而不只是更换布景。
- 安静章节仍改变目标、关系或理解。
- 高潮收束后立刻处理后果并交接下一目标。
- 同一谜题按现象、操作规则、因果模型和历史真相分层释放。

这些方法必须重新服务《硅基升维》的正典、人物弧和主题。

## 四、上下文隔离

- Writer 不读取 `clean_text.txt`。
- Writer 不读取整套 profile 文档。
- Writer 不读取参考书具体章节摘要和专有名词表。
- Planner 只读取经过抽象后的规划规则。
- 单章创作最多接收与本章有关的 3 至 5 条方法提示。
- 任何参考书内容不得写入 Canon Memory、Narrative Memory 或 Story State。
- 参考书研究结果必须保留 `REFERENCE_ONLY` 标记。

## 五、发现污染时的处理

若新章出现与参考书高度相似的名称、事件链、能力机制或世界答案：

1. 暂停提交该章。
2. 标记相似来源和相似层级。
3. 保留本章功能目标，重新设计实现方式。
4. 从《硅基升维》Canon、人物选择和当前环境重新推导事件。
5. 不用简单同义改写规避问题。
