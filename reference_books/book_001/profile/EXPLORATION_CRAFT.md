# 探索叙事技法

## 一、探索的定义

探索不是扫描未知区域，而是主角用有限信息主动建立、验证和修正模型。完整探索至少包含一次不可预知的反馈。

## 二、探索闭环

```text
现实问题
→ 暂时假设
→ 低成本试探
→ 反馈不完全符合预期
→ 风险或机会发生变化
→ 主角作出选择
→ 地图、身体、目标或认知被改写
```

如果“扫描—得到正确答案—执行”连续出现，探索会退化成设备操作。

## 三、让试探产生故事

一次有效试探至少应改变以下一项：

- 可通行范围；
- 可用资源；
- 对危险来源的判断；
- 对另一生命的分类；
- 身体完整度；
- 时间或能量预算；
- 当前目标；
- 对自身能力边界的认识。

## 四、失败不等于停滞

可轮换使用的失败类型：

- 测到了正确数据，却作出错误解释；
- 方案有效，但成本高于预期；
- 到达目标后发现目标性质不同；
- 避开一种风险，却进入另一种规则；
- 获得能力，同时失去原有优势；
- 与他者建立联系，却暴露了自己；
- 发现答案，但当下无法验证。

失败应留下可用信息，不能只是把主角推回原点。

## 五、探索对象轮换

为了避免长期重复，可以轮换主探索对象：

- 环境：材料、温度、路径、能源、空间结构。
- 身体：损伤、接口、记忆、感知、复制边界。
- 生命：识别、交流、捕食、协作、误解。
- 规则：信号、网络、预测、控制、代价。
- 社会：身份、权力、交易、责任、信任。
- 历史：遗迹、记录、被删除的信息、不同版本。
- 自我：来源、欲望、判断依据、选择权。

换对象时仍需保持前一阶段的后果。

## 六、安静探索

探索不必总是遇险。观察、等待和比较也可以成立，但必须让主角在等待后改变一种判断或安排。安静章最常见的有效结果是：发现规律、重新分配资源、决定不追某个答案、选择新的观察位置。

## 七、CH002 的可用方法

CH002 不宜重复 CH001 的“深度扫描—移动—再扫描”。可采用：

1. 仅做一次有明确成本的身份字段读取。
2. 结果显示字段为空但校验合法，排除普通损坏。
3. 外部压力使序不能继续深挖来源。
4. 序必须在“追查身份”和“维持意识/求生”之间选择。
5. 它保留一个可复查证据，并调整下一步行动。

这样，信息揭示会成为选择压力，而不是设定播报。

## 八、探索章自检

- 主角提出了什么假设？
- 哪个反馈偏离预期？
- 试探付出了什么成本？
- 探索结束后有什么不可恢复到原状？
- 新钩子是否来自探索结果？
- 本章是否换了探索对象或反馈形式？
