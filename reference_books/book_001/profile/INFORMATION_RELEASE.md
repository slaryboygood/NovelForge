# 信息释放研究

## 一、核心原则

长篇悬念不是把答案藏得越久越好，而是让同一问题在不同阶段产生不同层级的可用答案。读者每次都应得到东西，同时发现原先的问题问得还不够深。

## 二、四层释放法

### 第一层：现象

主角感知到异常，但不知道性质。信息只需要足够让它采取行动。

### 第二层：操作规则

主角确认异常在什么条件下出现、怎样影响当前行动、能否重复验证。此时不必解释来源。

### 第三层：因果模型

多个事件允许主角提出较稳定的解释，并据此预测结果。模型可以仍然不完整甚至部分错误。

### 第四层：历史或终局真相

来源、制造者意图、被掩盖的历史和终局意义，应在相应故事弧中通过事件验证，不能只靠一次资料读取全部交付。

## 三、再次出现的节奏

不建议规定机械的“每几章出现一次”，但可以采用以下规划判断：

- 当前生存规则：一至三章内必须再次被使用或验证。
- 当前篇章悬念：每个三至五章小组至少有一次推进、反证或代价。
- 卷级谜题：篇章结尾可以改变问题的层级，不必每章提名。
- 终局秘密：只向当前章节释放与行动有关的一小部分，Writer 不应读取完整答案。

重复提及不等于推进。只有新增证据、排除解释、改变风险或迫使选择，才算推进。

## 四、信息应附着在哪里

优先顺序建议：

1. 行动结果：尝试后出现反常反馈。
2. 环境证据：材料、痕迹、信号或空间结构与预期冲突。
3. 他者行为：另一角色隐瞒、误解或使用同一规则。
4. 主角能力：新感知揭开旧事件的另一层。
5. 文档与讲述：只补足行动无法表达的部分，并允许来源有立场或错误。

不要让数据库、遗迹记录或导师一次性解释完整世界观。

## 五、问题链设计

一个谜题可以按以下方式升级：

```text
它是什么？
→ 它何时出现？
→ 它怎样影响我？
→ 谁能利用它？
→ 为什么它被隐藏？
→ 我是否接受由它给出的答案？
```

每个阶段只回答当前行动需要的问题。

## 六、CH001/CH002 的信息分工

当前章纲已经给出清楚边界：

- CH001：建立内部异常节律和外部同频回应，并允许短暂看见制造者/用途为空且校验合法；只发现现象，不调查、不解释。
- CH002：正式验证身份字段“空但校验合法”的操作矛盾；确认不是普通损坏，但不能解释来源、制造目的或终局含义。

这是作者已经确认的信息分工，优先级高于参考研究：CH001 负责发现，CH002 负责调查。当前正文已清空，后续写作按该作者决定执行。

## 七、信息释放检查

- 本章给了读者什么可确认的新信息？
- 它排除了哪个旧解释？
- 它怎样改变主角下一步行动？
- 是否同时泄露了本应留到后续故事弧的答案？
- 是否只重复悬念，没有新增证据？
- 信息是否主要由现场事件承担？
