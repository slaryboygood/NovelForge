# NovelForge 使用建议

> 本次研究不修改 NovelForge、当前 Skills、Writer Prompt、Story State 或章纲。本文件只说明后续经作者批准后怎样使用研究结果。

## 一、四级使用边界

### A. Arc Planner 可读取

- `ARC_RHYTHM.md`
- `INFORMATION_RELEASE.md`
- `LONG_FORM_FRESHNESS.md`
- `HOOK_LIBRARY.md` 中的功能类型

用途是检查连续篇章的目标递进、不可逆变化、信息层级和新鲜度轴。

### B. Skill 可沉淀

只沉淀可复用操作方法，不存参考书情节、专名和原句。建议优先改进现有 Skill，而不是立刻增加数量。

### C. 单章创作边界可读取

Writer 每章最多获得 3 至 5 条与当前 ChapterPlan 直接相关的规则，例如：

- 本章感知只来自当前载体。
- 至少一次反馈偏离序的预期。
- 只展示影响选择的数字。
- 结尾钩子必须由本章行动产生。

### D. 只供 Codex/作者研究

- `BOOK_PROFILE.md`
- 全书统计数字
- 具体抽样章节记录
- 源文本和清洗文本
- 参考书阶段演变与缺点

这些内容不进入模型写作上下文。

## 二、建议完善的 5 个能力

### 1. 非人感知与决策

优先增强现有 `silicon-nonhuman-awakening-craft`，增加“载体允许的感知—暂时假设—主动选择—代价”检查，不建议另建重复 Skill。

### 2. 探索状态变化

增强现有“探索感”能力，要求每次探索改变地图、身体、目标、风险或认知中的至少一项，并禁止连续“扫描—正确答案—执行”。

### 3. 连续章节递进

作为 Planner 侧能力，检查 3/5/10/20 章单位内的问题升级、失败策略、规则发现和不可逆变化。它不负责写正文。

### 4. 信息分层释放

作为 Planner 侧能力，给谜题标记现象、操作规则、因果模型、历史真相，并控制 chapter-visible 范围。

### 5. 长篇新鲜度审计

作为规划或人工审查工具，记录环境、身体、规则、目标、关系、尺度、知识、能动性八个轴。它不打文学分，只提示重复风险。

## 三、Arc Planner 应采用的规则

每个篇章至少输出：

- 主问题和最初理解；
- 一次必须失败的合理策略；
- 一项可操作的新规则；
- 一次不可逆状态变化；
- 延续到后续的成本；
- 本篇回答的问题；
- 由答案产生的下一问题；
- 本篇改变的新鲜度轴；
- 高潮后如何交接下一目标。

规划器不得用“收集—解锁—升级—Boss”代替因果递进，也不得为了填满目标章数生成并列任务。

## 四、Writer Prompt 绝不能接收的内容

- 参考书全文或大段章节摘要。
- 参考书角色、地点、生命、文明和专有术语。
- 参考书具体成长路线、篇章顺序与终局结构。
- 全书统计表、阶段演变分析和八轴完整矩阵。
- 一整套钩子库和全部非人写作规则。
- “模仿参考书文风”之类指令。
- 当前章节不可见的 Author Intent、终局秘密和卷后谜底。

Writer 只需要当前 ChapterPlan、精简 Context Pack、当前可见 Canon，以及少量与本章相关的创作边界。

## 五、当前项目的应用顺序

1. 执行作者已经确认的 CH001/CH002 信息分工。
2. CH001 允许短暂发现“制造者/用途为空且字段合法”，但不调查、不解释原因、来源和意义。
3. CH002 正式验证该异常，排除普通损坏，并把身份谜题推进到操作规则层。
4. 人工确认当前章节后，再用实际结果校正下一章。
5. 完成数章后，再审 A01 是否需要去除过强的游戏任务结构。
6. 只有出现真实重复问题时，才更新对应 Skill 或 Planner 规则。

## 六、CH001 对照说明

当前没有 CH001 正文可供逐句比较。根据现有章纲和此前人工评价，成熟参考样本与《硅基升维》历史候选稿的最大差距，不在辞藻，而在“每次感知都是否推动新的判断与后果”。

CH001 应保留 17 秒倒计时、有限残能、三根可驱动硅晶须、异常节律和主动选路；可以短暂读到制造者/用途为空且校验合法，但不得追查或解释。CH002 才负责正式验证、排除普通损坏并推进身份谜题。

## 七、验收标准

研究成果被正确使用时，应出现以下结果：

- 章纲更连贯，但 Writer 上下文没有明显变长。
- 主角成长体现为行动和判断变化，不是技能清单膨胀。
- 每章有状态变化，但节奏不被固定模板绑死。
- 谜题持续推进，同时没有提前泄露终局答案。
- 正文保持《硅基升维》自己的硅基语汇、人物弧和主题。
